# TypeScript Hover Types

Hover over any **underlined identifier** to see its type. This demonstrates TypeScript's type inference in action.

## Inferred Types

TypeScript automatically infers types. Hover over the underlined variables to see their types:

```typescript twoslash
const config = {
  apiKey: "sk-123456",
  baseUrl: "https://api.example.com",
  timeout: 5000,
  retries: 3
};
//    ^?

const response = fetch(config.baseUrl);
//    ^?
```

## Function Signatures

See complete function signatures on hover:

```typescript twoslash
interface User {
  id: string;
  name: string;
  email: string;
  role: "admin" | "user" | "guest";
}

function createUser(name: string, email: string, role: User["role"] = "user"): User {
//       ^?
  return {
    id: crypto.randomUUID(),
    name,
    email,
    role
  };
}

const admin = createUser("Alice", "alice@example.com", "admin");
//    ^?
```

## Generic Types

Twoslash shows how generic type parameters resolve:

```typescript twoslash
type Result<T, E = Error> =
//   ^?
  | { success: true; data: T }
  | { success: false; error: E };

function fetchData<T>(url: string): Promise<Result<T>> {
//       ^?
  return fetch(url)
    .then(res => res.json())
    .then(data => ({ success: true as const, data }))
    .catch(error => ({ success: false as const, error }));
}

interface ApiUser { id: string; name: string; }

const userResult = fetchData<ApiUser[]>("/api/users");
//    ^?
```

## Array Methods

See return types of array transformations:

```typescript twoslash
const numbers = [1, 2, 3, 4, 5];
//    ^?

const doubled = numbers.map(n => n * 2);
//    ^?

const evens = numbers.filter(n => n % 2 === 0);
//    ^?

const sum = numbers.reduce((acc, n) => acc + n, 0);
//    ^?

const strings = numbers.map(String);
//    ^?
```

This feature makes TypeScript documentation interactive - you can explore types without running the compiler!
