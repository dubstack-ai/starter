Use snippets for content that appears on multiple pages. Keep the source in the `snippets/` directory, then import it wherever readers need it.

<Note>
  Snippet files are reusable content sources. They do not need to appear as standalone pages in navigation.
</Note>

## Content snippets

Create a focused MDX file:

```mdx snippets/prerequisites.mdx
Before you begin, make sure you have:

- Node.js 18 or higher
- Access to the project repository
- The required environment variables
```

Import it with a root-relative path:

```mdx guide.mdx
---
title: "Install the client"
description: "Install and configure the example client"
---

import Prerequisites from '/snippets/prerequisites.mdx';

<Prerequisites />

## Installation

Continue with the installation steps.
```

You can also use relative imports when that makes editor navigation clearer:

```mdx
import Prerequisites from '../snippets/prerequisites.mdx';
```

## Reusable variables

Export named constants for values that appear across several pages:

```mdx snippets/variables.mdx
export const sdkVersion = '3.2.0';
export const baseUrl = 'https://api.example.com/v1';
```

Import the values where they are needed:

```mdx guide.mdx
import { sdkVersion, baseUrl } from '/snippets/variables.mdx';

The current SDK version is **{sdkVersion}**.

All requests use `{baseUrl}`.
```

## Parameterized snippets

Export an arrow function when a repeated block needs a small amount of page-specific data:

```mdx snippets/endpoint-note.mdx
export const EndpointNote = ({ method, path }) => (
  <Note>
    This guide covers the <code>{method} {path}</code> endpoint.
  </Note>
);
```

Pass props when rendering the snippet:

```mdx guide.mdx
import { EndpointNote } from '/snippets/endpoint-note.mdx';

<EndpointNote method="POST" path="/v1/users" />
```

<Warning>
  Keep parameterized snippets simple. Use plain JSX inside arrow functions and avoid hiding required setup steps behind complex reusable logic.
</Warning>

## Compose snippets

A snippet can import another snippet:

```mdx snippets/authentication.mdx
import Prerequisites from '/snippets/prerequisites.mdx';

<Prerequisites />

## Authentication

Send a bearer token in the `Authorization` header.
```

## Best practices

- Keep each snippet focused on one reusable concern.
- Use clear file names that describe the content.
- Prefer a normal page section when content is used only once.
- Avoid deeply nested imports.
- Review every page that consumes a snippet before publishing a breaking change.
