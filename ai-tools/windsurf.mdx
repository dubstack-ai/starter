Use Windsurf's Cascade assistant to draft and review MDX documentation in your local repository.

## Prerequisites

- Windsurf installed and authenticated
- Your documentation repository cloned locally

## Setup

<Steps>
  <Step title="Open the docs repository">
    Open the directory that contains `dubstack.json`.
  </Step>

  <Step title="Load the project guidance">
    Review the starter's `AGENTS.md` file with Cascade before making changes. Add project-specific terminology, style rules, and review requirements there so other tools can use the same instructions.
  </Step>

  <Step title="Describe a bounded task">
    Tell Cascade which page or source file to inspect, what outcome the reader needs, and what must remain unchanged.

    ```text
    Review quickstart.mdx for missing prerequisites and unclear verification
    steps. Keep the existing navigation and do not invent commands.
    ```
  </Step>

  <Step title="Review and publish">
    Inspect the generated diff, validate the rendered page, then commit and push through the connected Git workflow.
  </Step>
</Steps>

## Useful prompts

```text
Create a focused MDX guide from this source file. Add frontmatter, a short
overview, ordered steps, and one verification section. Reuse existing terms
from the repository.
```

```text
Review the changed docs for broken relative links, missing alt text, and a
navigation update that may be required in dubstack.json.
```
